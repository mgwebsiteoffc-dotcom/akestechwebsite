## Publish the blogs
Every file in `blogs/` carries an SEO metadata header (title, meta description, slug, keywords, schema, image brief, alt text) followed by the full article. Posts can be pasted into the existing admin (`/admin/blogs.php`) — the CMS already renders Article + FAQ + Breadcrumb schema and the TOC.

## Data honesty rule used throughout
Where a number could not be verified from a live platform (Search Console, GBP admin, Instagram Insights, Ahrefs/Semrush), it is labelled **Estimated**, **Not Available**, or **Requires Verification**. Nothing in this kit invents rankings, volumes, or competitor metrics.
